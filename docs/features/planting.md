# Planting

Planting is one word for two behaviors, so users find it in both places. Each part keeps its own rules in its own doc.

- **Spiral:** a roaming mode that walks out from the current point and back. See [roaming.md](roaming.md).
- **Circles:** a route switch that walks a circle around each stop. See [routes.md](routes.md).

## Why

- **A switch, not a mode, on routes.** It combines with any paste build mode, so a user can plant a teleport or a walkable route.
- **Two shapes, one name.** The spiral and the circles share no code. They share the user's goal: cover the ground around a point. One wiki page ([planting.html](../wiki/planting.html)) names both so the feature is not hidden inside Routes.
- **Hidden on one game path.** The Pokémon Go path hides every Planting entry point ([guided-paths.md](guided-paths.md)). Stored values stay.
