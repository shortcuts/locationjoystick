Capture coordinates

Capture coordinates collects map links from other apps into a list on this device, then lets you save that list as a route. The floating widget is not required. With Capture mode turned on, opening a map link keeps you in the app you were using instead of opening Google Maps.

Open Capture

Open Capture from the Home screen or the side menu, next to Map, Routes, and Favorites. The page stays open when you leave for Android settings or another app and come back. You can also press and hold the floating widget's paste button, then tap the Capture shortcut that appears beside it.

Set up Capture

The Capture page lists five short steps. Orange underlined words open the matching Android setting. Come back here when you are done — this page stays open.

  • Turn on Capture mode, then choose List to add each location, Jump to move there immediately, or both. If the list already has points when you turn the mode on, choose Clear (the main action) to start fresh or Keep to continue.
  • Set this app as default browser — tap default browser, then choose this app as the Browser app. (A system popup that only says "set as default browser" often does nothing on Samsung phones.) A green check appears after this app is the default browser.
  • Turn off Google Maps supported links — tap Google Maps supported links and turn off opening supported links. If Maps keeps that on, Google Maps links go straight to Maps and this app never sees them. Use the same link later if you want to turn that setting back on.
  • Turn on supported links for this app — tap supported links for this app and allow this app to open those links. Use the same link later to turn that off.
  • When you are done, restore default browser — tap restore default browser and pick your usual browser again, then reverse steps 3 and 4. This app cannot switch Chrome back by itself. While Capture is off, step 5 is highlighted in green so it is easy to find.

With Capture mode off—or with both List and Jump unchecked—links pass through without being collected or changing your location. Tap the short Pass-through row to choose an installed browser. Google Maps links are sent to the Google Maps app first while Capture mode is off, even if its supported-links switch is off; if Maps is unavailable, they use your chosen browser.

The browser list refreshes when you return from Android settings. It continues to show your installed browsers even while this app is selected as the default browser.

When Capture mode and List or Jump are on and this app is the default browser, a Ready line appears and says whether a Google Maps link will be added, jumped to, or both.

Collect and save

With the settings above in place, tap a map link in another app. List adds the point without moving, Jump moves there without adding, and using both does both immediately. A short message confirms what happened and the other app stays on screen. Open Capture later to see the list. Use Copy, Last (removes the most recent point), or Clear on the row above the route name. Enter a route name and tap Save as route when you have at least two points. The new route appears under Routes.

The on-screen list stays in the order you captured the points, inside an orange box, so Last always drops the most recent one. Optimize proximity is on by default when you copy or save — the same option as when you paste coordinates into a route. It reorders the points so each stop is near the previous one. Choose Keep original if you want the capture order instead.

The same link tapped twice in a row is not added twice. A later repeat of an earlier point is kept, so a loop in the list is allowed.
