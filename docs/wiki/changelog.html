Changelog

What's new in each release. Download the latest APK from GitHub Releases.

0.20.0, September 6, 2026

New & Improved

General
  • Settings now shows two columns on tablets, matching the home screen's layout.
  • Redesigned the top bar: the title now sits at the start, the start/stop button is centered, and each screen's extra actions are tucked into a single 'More actions' menu.

Fixes

Click-to-Move / Teleport
  • Fixed a bug where your reported speed could stay stuck at a nonzero value after a walk finished.
Favorite Locations
  • The delete confirmation for a favorite now names the favorite being deleted.
  • Menu options for adding a favorite now use consistent, readable labels.
  • The empty-favorites message is now the same everywhere it appears.
General
  • Long blocks of text no longer stretch edge-to-edge on tablets and foldables.
  • Fixed a checkbox that could be focused twice by screen readers.
Group Sync
  • A missing value now shows 'Unknown' instead of a dash that looked like a separator.
  • Switch descriptions on the Group Sync screen now read as complete sentences.
  • Screen readers now announce the QR code button as one item instead of two.
Map (MapLibre)
  • The map's hint text no longer wraps awkwardly on narrow screens.
  • Search result rows are now easier to tap.
Mock Location Engine + GPS Realism
  • Long-pressing the start/stop bar now shows the full location name when it's too long to fit.
Route System
  • Starting a walk right after canceling a route replay could briefly snap your position back to the old route.
  • The delete confirmation for a route now names the route being deleted.
What's New Popup
  • The 'What's new' badge no longer appears during onboarding, before you've reached the main app.

  • A 'What's new' popup shows what changed after each update.

  • The popup not loading its highlights on alpha/beta builds.

Fixes

Mock Location Engine + GPS Realism

  • Idle speed wobble no longer follows the active speed profile.
  • Altitude jitter is sampled fresh each tick instead of drifting as a random walk.

0.18.0, August 30, 2026

Fixes

Floating Widget
  • The altitude value in debug stats rounding to a whole number instead of showing decimal precision.
Mock Location Engine + GPS Realism
  • Elevation taking time to catch up instead of updating right away after starting to spoof or teleporting.
  • Altitude variation sometimes landing on suspiciously round numbers instead of natural-looking values.

0.17.0, August 28, 2026

New & Improved

Floating Widget
  • An opt-in debug stats panel in the floating widget, showing live coordinates, speed, altitude, accuracy, bearing, and update rate.
Foreground Service
  • A setting to hide the notification icon while spoofing is active.
Mock Location Engine + GPS Realism
  • GPS altitude can now follow real-world elevation automatically, with an adjustable amount of natural variation, plus a quick override button in the floating widget.
  • The 'vary altitude' checkbox and its amount field are now combined into a single control.
Onboarding
  • Onboarding's 'set as fake GPS app' check can now be bypassed permanently, for setups where spoofing already works despite the check not detecting it.
  • If the 'set as fake GPS app' check doesn't detect your setup, the 'Skip' option now explains what it means before you confirm, instead of skipping instantly.
Route System
  • An option to walk via roads to a route's starting point before playback begins.

Fixes

Click-to-Move / Teleport
  • A road-following option not applying correctly to newly added route points.
Export / Import
  • Importing a backup with every widget/map feature explicitly turned off reverting to the default set instead of staying empty.
Favorite Locations
  • Favorite location coordinates sometimes displaying in the wrong number format depending on your phone's language settings.
Floating Joystick
  • The joystick sometimes keeping its last direction after you released or unlocked it.
Floating Widget
  • The floating widget not disappearing right away when its setting was turned off mid-session.
  • The altitude override field in the floating widget not accepting keyboard input.
Foreground Service
  • The hide-notification-icon setting sometimes turning itself back off.
General
  • Coordinate, speed, and roaming distance fields rejecting a comma as the decimal separator.
Mock Location Engine + GPS Realism
  • The reported speed not resetting to zero right after a route or walk finished.
  • Your position freezing incorrectly, instead of holding steady, while spoofing was paused.
Route System
  • The travel direction shown during route playback and roaming.

0.16.0, August 25, 2026

New & Improved

Floating Widget
  • A setting to hide the floating widget overlay.
General
  • Lowered the minimum supported Android version, so more phones can now install the app.
Group Sync
  • Distance and a wait-time hint are now shown when teleporting to the group leader as a follower.
Hide Teleport Features
  • A setting to hide every teleport button throughout the app, leaving only walking and route playback as ways to move.
Route System
  • Buttons to jump straight to the next or previous stop while a route is playing.
  • A route can now be pinned to its own speed, independent of the app's overall speed setting.

Fixes

Export / Import
  • Some widget and map features going missing after importing settings.
Favorite Locations
  • Imported favorites losing their category.
Floating Widget
  • The floating map's route controls sometimes becoming unreachable after reopening the panel.
Group Sync
  • A follower's position not saving properly while following a leader.
  • The group leader's stop/start state not always reaching followers.
  • No message appearing when teleporting to a leader before their position is known.
Last Remembered Location
  • Your last known location only saving when you stopped, instead of throughout the session.

0.14.0, July 16, 2026

New & Improved

Export / Import
  • 'Reset all data' button in Settings, clears all favorites, routes, and settings without needing your phone's own app data reset option.
Favorite Locations
  • Favorites now has a search bar to filter by name, and hot locations are grouped under category headers.
  • The search bar now accepts raw coordinates (e.g. '35.6762, 139.6503') typed directly, no need to search by name.
Group Sync
  • Followers now walk toward the leader's position instead of teleporting instantly, and reconnect more reliably after repeated network hiccups.
Speed Profiles
  • Two more speed profiles, Slow Walk and Drive.
Theme
  • Light mode, a high-contrast light theme option, alongside the existing dark theme.

Fixes

Export / Import
  • A regression that broke importing routes from GPS Joystick.
Floating Widget
  • Various fixes to the floating map's route controls and walk/replay handling.

0.13.0, July 4, 2026

New & Improved

Export / Import
  • GPX import now works with files that contain only waypoints, without a track or route section.
Group Sync
  • Followers now reconnect automatically after a disconnect, including after a device or app restart.
Mock Location Engine + GPS Realism
  • The Start/Stop button now shows the name of the location you're spoofing to.
  • Removed the elevation controls feature.
Speed Profiles
  • Lowered the minimum speed setting so you can go slower than 0.1 mph.
Tap to Walk
  • Tap to Walk, quick-walk on the floating map with one tap, plus an optional screen overlay to tap-to-walk over other apps.
  • Compass-aware tap-to-walk orientation, calibrated for popular AR game maps.

Fixes

Click-to-Move / Teleport
  • A bug where finishing one walk could wipe the path of a different, newer walk.

0.12.0, June 24, 2026

New & Improved

Click-to-Move / Teleport
  • 'Walk via roads' and Roaming now handle a slow or unreliable routing server better, retrying automatically before falling back to a straight line.
Export / Import
  • A file containing multiple tracks or routes now imports each one as its own separate route instead of merging them.
Floating Widget
  • Settings → Menus now has one combined 'App Features' list with drag-to-reorder, replacing the separate widget and map sections. Toggle each feature for the widget, the map, or both from the same place.
Group Sync
  • Followers can now reconnect automatically after the leader's device restarts.
Mock Location Engine + GPS Realism
  • Removed the redundant start/stop button from the Map screen. The top bar's start/stop control already works on every screen.
  • The top bar start/stop button now stays centered consistently across all screens instead of shifting position.

Fixes

Mock Location Engine + GPS Realism
  • The start/stop button's accessibility label, which was incorrectly announcing the screen title instead of its action.

0.11.0, June 21, 2026

New & Improved

Deep Links & Location Sharing
  • The app can now open location links shared from Google Maps, including its Share button and shortened links, and shows an error message if a link can't be opened.
Group Sync
  • Group Sync now reconnects properly after the app restarts, and automatically leaves a group if the leader disappears.
Mock Location Engine + GPS Realism
  • Redesigned the top bar start/stop button as a compact icon, and fixed a small accuracy issue in joystick movement.
QR Share / Transfer
  • QR transfer now sends your data over a single QR code via local Wi-Fi instead of several scan-in-sequence codes: faster and more reliable, with no size limit. You can also join by typing a 6-character code instead of scanning.
Roaming Mode
  • Roaming and 'walk via roads' now always use walking paths, even when your speed profile is set to Bike.
Speed Profiles
  • Removed the 54 km/h cap on custom speed profiles.

0.10.0, June 18, 2026

New & Improved

General
  • Drawer menu items reordered to match the home screen, and the Website link now shows an external-link icon.
Group Sync
  • Group Sync, share your spoofed location across multiple devices on the same Wi-Fi network. One device leads, others follow, using a 6-character code or QR scan to join. No account needed.
  • Each follower now applies its own jitter, so devices in a group don't show identical coordinates.
Route System
  • Removed outdated Copenhagen hot routes and favorites that no longer apply.
