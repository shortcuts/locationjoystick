Follow a friend with Group Sync

Make one phone follow another phone's fake location.

Before you start

  • Both phones are on the same Wi-Fi network.
  • Both phones finished first-run setup.

Steps

  1. On the leader phone, open Group Sync from the side menu.
  2. Tap Create group: I'm the leader. A QR code and a join code appear.
  3. On the follower phone, open Group Sync.
  4. Scan the QR code, or type the join code.

Result

The follower starts walking toward the leader. It follows the leader's moves and speed.

More

If joining fails, see limitations. Learn all controls on the Group Sync page.
