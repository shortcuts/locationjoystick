Game setup

Pick the game you play, and the app hides the features that game does not need. Nothing is deleted, and no setting changes.

The three setups

Each setup has its own list of hidden features. Everything else stays on.

Default

Preselected. Shows every feature. Hides nothing.

Pokémon Go

Hides Planting. Planting is in Settings, in the roaming sheet, on the floating map, in the widget, and in the route screens (paste coordinates, start route, route details). Routes you already set to plant keep that setting.

Pikmin Bloom

Hides Tap to Walk and Reconnect accessory. Both are in Settings under Menus.

Choose or change

The last step of first setup asks which game you play. You can also change it later.

  1. Pick Default, Pokémon Go, or Pikmin Bloom.
  2. Tap Start using locationjoystick.
  3. To change it later, open Settings → General → Game setup.

What stays the same

  • Your saved settings for hidden features are kept.
  • Switching back shows every hidden feature again.
  • Your game setup is included when you export a backup.
