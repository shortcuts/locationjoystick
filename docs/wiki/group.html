Group Sync

Share one location across several devices on the same Wi-Fi network. One device is the leader and sends its position. The other devices follow. No account is needed. See the privacy policy.

Set up a group

Before you start, put every device on the same Wi-Fi network and set up mock location on each one.

  1. On the leader, open Group Sync from the side menu and tap Create group: I'm the leader.
  2. The leader screen shows a QR code and a 6-character join code. The code stays on that screen while the group runs.
  3. On each follower, open Group Sync. Scan the QR code, or tap Enter code and type the join code.
  4. The follower joins and starts following at once. Follow leader is on.

Scanning asks for camera access. Typing the code needs no extra permission. A leader can run one group at a time.

Leader controls

ControlDescription
QR code Shows the QR code and the join code. Tap the refresh icon for a new QR code. The join code stays the same.
Sharing toggle When on, the leader sends its position once a second. Turn it off to pause sharing and stay in the group.
Control API toggle Off by default. Lets other apps on your Wi-Fi control this device. Turns itself off when you leave the group or restart the app. Developers: see the Control API reference.
Regenerate key Shown with the Control API address. Makes the old key stop working.
Leave group Removes this device from the group. Followers lose the connection and stop getting updates.

Follower controls

ControlDescription
Follow leader toggle On by default when you join. When on, the device walks toward the leader. Turn it off to pause following and stay in the group. Moving the joystick also turns it off.
Follow leader teleports toggle On by default. When the leader teleports, or stops and restarts somewhere new, your device jumps there too. Turn it off to walk there instead. Hidden when Hide teleport features is on in Settings. Your device then always walks.
Teleport to leader now Jumps to the leader's last known position at once. Shown while Follow leader is on. A badge next to it shows the suggested wait before you jump. If the app does not know the leader's position yet, try again in a moment.
Leave group Disconnects from the leader and clears the saved connection.

After you close the app

The app saves a follower's connection. If Follow leader was on, following restarts when you open the app again, even after a phone restart. The app also saves a leader's role. The group starts again when you open the app. You do not need to tap Create group again.

How followers catch up

A follower does not jump to the leader's position. It walks there at the leader's speed. While the leader stands still, it uses the speed set on that device: Slow Walk, Walk, Run, Bike, or Drive.

While the leader keeps moving, the gap stays the same. Use Teleport to leader now to close it. If the leader stops sharing and later starts again, followers pause and then jump to the leader's new location.

Troubleshooting

For other problems, see Troubleshooting.

ProblemFix
A follower never moves. Check that Follow leader is on for the follower and Sharing is on for the leader.
A device cannot reach the leader. Turn off mobile data and any VPN on that device. Both devices must use the same Wi-Fi network.
The join code finds nothing. Some phone hotspots block the code. Scan the QR code instead.
Followers cannot reconnect after the leader restarts the app. The leader's network address can change. Followers retry for a short time. If that fails, rejoin with the QR code or the join code.
