Getting Started

In this tutorial you install locationjoystick, grant three permissions, and walk your fake location across the map. It takes about ten minutes. Each step ends with a result you can check.

1. Install the app

  1. Download the latest APK from GitHub Releases.
  2. Open the downloaded file. If Android asks you to allow installs from unknown sources, turn it on for your browser or file manager. Then try again.
  3. If Google Play Protect shows "App scan recommended", tap Install without scanning.

Result: The locationjoystick icon appears on your home screen. Tap it to open the app.

2. Grant the three permissions

The first time you open the app, it asks for three permissions. Setup ends when all three are granted.

  1. Location. Tap Allow and choose Precise location.
    Result: The next setup screen appears.
  2. Display over other apps. The app opens Settings. Turn on locationjoystick, then go back to the app.
    Result: The setup screen shows this permission as granted.
  3. Mock location app. Turn on Developer options and choose locationjoystick. Follow Turn on Developer options below, then return here. Tap Check again.
    Result: The check passes and the Map screen opens.

The app may also offer one optional step. It keeps taps accurate when your game map rotates. Skip it if you don't use Tap to Walk.

Result: The Map screen opens with a marker at your real location.

Turn on Developer options

Android hides these settings until you turn them on. The mock location app choice lives here.

  1. Open Settings, then About phone.
  2. Tap Build number seven times. Android says "You are now a developer."
    Result: Developer options appears in Settings.
  3. Open Settings → Developer options. Scroll to the Debugging group and tap Select mock location app.
  4. Tap locationjoystick.
    Result: locationjoystick is the selected mock location app.

If the app is not in the list, or the check fails, see Troubleshooting.

3. Take your first walk

  1. On the Home screen, tap the start button at the top. It turns on spoofing.
    Result: The button shows that spoofing is on.
  2. Open the side menu and tap Map.
    Result: The map opens with your marker on it.
  3. Long-press a street a few blocks away.
    Result: A menu opens at the point you pressed.
  4. Tap Walk here.
    Result: Your marker moves toward the point at your current speed, and the map follows it.

Want to jump instead of walk? Choose Teleport in the same menu. See Map for every option.

4. Stop spoofing

  1. Go back to the Home screen.
  2. Tap the start button again.
    Result: The button is off and shows where spoofing will start next time.

Update the app

  1. Download the new APK and open it.
  2. Android asks "Replace app?". Confirm. Your data stays.
