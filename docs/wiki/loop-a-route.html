Loop a route

Walk a saved route in a circle, as many times as you like.

Before you start

  • A saved route with at least two stops. See how to add a route.

Steps

  1. Tap the routes button on the map.
  2. Tap your route. A preview of its path appears.
  3. Check that Loop is on. It is on when the sheet opens.
  4. Turn on Return to start if you want a smooth walk back from the last stop.
  5. Tap Start.

Result

You walk to the first stop. Then the route plays from the first stop again each time it ends.

More

To stop, open the route controls on the map or the widget and tap Stop. See all replay options.
