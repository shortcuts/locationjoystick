Move to a new phone

Copy your routes, favorites, and settings to a new phone.

Before you start

  • Both phones are on the same Wi-Fi network.
  • locationjoystick is installed on the new phone.

Steps

  1. On the old phone, open Settings and tap the menu at the top right.
  2. Under Export, tap Export via QR code. A QR code and a short code appear.
  3. On the new phone, open Settings and tap the menu at the top right.
  4. Under Import, tap Import from QR code. Scan the code, or tap Import via code and type it.
  5. Choose Add to my data or Replace all data.

Result

Your routes, favorites, speed profiles, and settings appear on the new phone.

More

Captured location lists and permissions do not move. Set up permissions again on the new phone. For a file backup, see Backup & Transfer.
