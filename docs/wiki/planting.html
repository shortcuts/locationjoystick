Planting

Planting walks you around a point instead of straight through it. It appears in two places. In Roaming, it walks a spiral that opens out, then tightens. In Routes, it walks a circle around each stop.

Some game setups hide Planting. See Game setup.

Planting spiral

Prerequisites: Pause or stop a playing route first.

  1. Tap the roaming button on the map.
  2. Choose Planting.
  3. Set the loop count. One spiral is one loop. Tick Expand only to walk the spiral out once and stop.
  4. Tap Generate to preview the path.
  5. Tap Start roaming.

The spiral is straight lines only. See Roaming for the sheet.

Planting circles on a route

On a route, Planting is a switch. Turn it on for any route style. The route walks a circle around each stop.

  • Turn it on before you start a route: see Routes → Planting.
  • Turn it on when you paste points: see Paste coordinates → Planting.

Planting turns Loop on. The saved route does not change.

Planting settings

Starting radius, ending radius, ring spacing, speed, expand only and loop count set the spiral. Circle radius sets the route circles. Defaults are in Settings → Roaming.
