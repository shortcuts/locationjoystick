Privacy Mode

Install a renamed copy of the app, so other apps on your phone do not see its name.

Before you start

  • Privacy Mode is only in the GitHub download. The Play Store version does not have it.
  • It only hides the name of the app from other apps.
  • The copy is a separate app with its own data. It starts with no favorites or routes.

Steps

  1. Open Settings → Privacy Mode.
  2. Turn on Privacy Mode. Read the notice and tap I understand.
  3. Type a name for the copy.
  4. Tap Start. If Android asks, allow this app to install apps, then tap Start again.
  5. Confirm the install on the Android screen.
  6. Open Developer options → Select mock location app and pick the copy.

Result

Your phone now has two apps. The copy shows the name you chose and a different icon colour.

To move your favorites and routes to the copy, use Backup & Transfer.

You can uninstall the original after you export your data. The app never does this for you.

Update and remove

  • After the original updates, tap Update to refresh the copy. You can change its name here too.
  • Tap Remove to uninstall the copy. Android asks you to confirm.
  • Turning the switch off hides the buttons. It does not remove the copy.

Limits and risks

  • You must pick the copy as the mock location app yourself. The app cannot do it.
  • Apps that read the mock location setting can still see it. Privacy Mode does not hide it.
  • The copy does not show Privacy Mode in its own Settings.
