Roaming

Roaming moves your location on its own, so you do not have to steer. Walk around the block picks random spots near you. Planting walks a spiral instead.

Start roaming

Prerequisites: Pause or stop a playing route first. Only one roaming mode runs at a time.

  1. Tap the roaming button on the map.
  2. Choose a mode.
  3. Set radius, distance, speed, or loop count. Defaults are in Settings → Roaming.
  4. Tap Generate to preview the path.
  5. Tap Start roaming. It keeps going with the screen off.

Changing speed during roaming replaces the speed you set here.

Walk around the block

Walks to random spots within a radius. Set the radius, the total distance and the speed on the sheet.

With Follow roads on, you walk along paths. Without it, you walk in straight lines. Return to start walks you back where you began.

Planting

The sheet has a second mode, Planting. See Planting.
