Troubleshooting

Find your problem in the list, then follow its steps. See Settings for spoofing and permission options.

Symptoms

  • locationjoystick is missing from "Select mock location app"
  • Spoofing does not work, another app is selected
  • The mock location check fails during setup
  • An app says "GPS signal not detected" or asks for location again
  • Spoofed location jumps back to your real location
  • The joystick or widget disappears after a restart
  • Cannot grant the overlay permission
  • A game shows a location or GPS error
  • The map is a black screen
  • The app crashes and you want to report it
  • The joystick does not move me
  • The notification icon is gone
  • A route will not start
  • A location link does nothing
  • Group Sync cannot find the leader

App missing from the "Select mock location app" list

  1. Open locationjoystick once. A freshly installed app never appears in the list.
  2. Turn Developer Options off and back on, or restart the phone.
  3. If you installed from a file on Android 12 or later, allow restricted settings first.
  4. Still missing: reinstall the app, then restart the phone.
  5. If installed in a work profile: open Developer Options inside that profile. Android keeps the selection per profile.

Another app holds the mock location slot

Spoofing does nothing when another app is set as the mock location app.

  1. Open Developer options in Settings.
  2. Scroll to the Debugging group and tap Select mock location app.
  3. Read which app is selected. Anything other than locationjoystick blocks it.
  4. Tap locationjoystick in the list.
  5. Return to locationjoystick and start spoofing again.

Notes: No Developer options entry? Turn it on first: see Turn on Developer options in Getting Started. If locationjoystick is missing from the list, see App missing from the list.

Mock location not detected

The mock location check fails or shows an error during setup.

  1. Restart the phone after you change the Developer Options setting.
  2. If spoofing already works, tap Skip next to the check during setup, then confirm the warning.
  3. Use Skip only after you confirm spoofing works.

App shows "GPS signal not detected" or asks for location again

  1. Open the Settings app.
  2. Tap Apps, then tap the app that shows the error.
  3. Tap Permissions, then Location.
  4. Select Allow all the time.
  5. Restart that app.

Allow only while using the app and Ask every time are not enough for these apps.

Spoofed location jumps back to your real location

Google's location services can refresh your real position and override the spoof. Change one step at a time, and test after each. Steps run from least to most invasive.

  1. Open Settings → Location. Set the mode to GPS only (or "Device only"), and turn off Wi-Fi scanning and Bluetooth scanning (under "Improve Accuracy").
  2. Confirm no other app holds the mock location slot. See Another app holds the mock location slot.
  3. Last resort: in your Google account settings, turn off Location History and Location Sharing.
  4. Last resort: open Settings → Apps → Google Play Services → Permissions → Location and set Don't allow. Other apps that use Google location may stop working.
  5. Last resort: turn off Find My Device. You then cannot locate or lock the phone remotely.

To get your real location back: Stop spoofing in locationjoystick, undo the settings you changed, and restart the app you want to use.

Overlay permission resets on restart

The joystick or widget disappears after restarting the phone. This is a known issue on MIUI and ColorOS.

  • Grant the permission again after each restart, or allow locationjoystick in your phone's autostart settings.
  • See Overlays to show the controls again.

Cannot grant the overlay permission

This affects Android 12 and later when you install from a file instead of the Play Store.

  1. Open the Settings app.
  2. Tap Apps (sometimes "Application Manager").
  3. Tap locationjoystick.
  4. Tap the ⋮ menu, top-right.
  5. Tap Allow restricted settings.
  6. Return to locationjoystick and run setup again.

No ⋮ menu means your phone does not need this step.

A game shows a location or GPS error

Games can detect mock location apps. This is outside this app's control.

The map is a black screen

  1. Turn on Wi-Fi or mobile data. The map downloads street images the first time you open an area.
  2. Leave the map screen and open it again.
  3. Still black with internet: swipe the app away from Recents and reopen it.

Report a crash

Tell us what happened so we can fix it.

  1. Open the bug report form.
  2. Describe what you did before the crash.
  3. Fill in your app version and Android version.
  4. Say whether the main Map screen works on your device.

A log makes the bug easier to fix, but you can send the report without one.

Attach a log (for developers)

You need a computer with Android platform-tools and a USB cable. An emulator needs no cable.

  1. Turn on Developer options: see Turn on Developer options in Getting Started.
  2. Open Settings → Developer options and turn on USB debugging.
  3. Connect the phone to the computer. Tap Allow if prompted.
  4. Run adb logcat -c to clear the old log.
  5. Repeat the steps that crash the app.
  6. Run adb logcat -d -b crash and copy the output. If empty, run adb logcat -d and copy the last 200 lines.
  7. Paste the log into the Logcat output box of the bug report form.
