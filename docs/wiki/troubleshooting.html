Troubleshooting

Common setup problems and how to fix them.

  • The setup screen grants each permission the app needs, one step at a time.
  • If "Set as fake GPS app" won't pass but spoofing works, tap Skip next to it.
  • The Troubleshooting link at the top of that screen opens this page.

App shows "GPS signal not detected" or asks for location again

Some apps need the strongest location permission. Grant it by hand:

  1. Open the Settings app.
  2. Tap Apps, then tap the app that shows the error.
  3. Tap Permissions, then Location.
  4. Select Allow all the time.
  5. Restart that app.

Allow only while using the app and Ask every time are not enough for these apps.

A game shows a location or GPS error and won't let you play

Covers "Failed to detect location (12)", "location error 12", and similar red GPS errors.

  • The error comes from the game, not from locationjoystick.
  • The game found the marker that every mock location app leaves on the reported position.
  • locationjoystick cannot hide that marker, and will not add a way to hide it.
  • Players who get past this check root the phone and use a Smali Patcher or LSPosed setup. That is a separate, advanced modification.
  • Read this community thread for that approach. Rooting carries its own risks and is outside locationjoystick support.
  • If you do not play a game like this, ignore this section. Everything else works without root.

Allow restricted settings (Android 12+ installed from a file)

Android 12 and later block the overlay permission for apps installed from a file. Skip this section if you installed from the Play Store.

  1. Open the Settings app.
  2. Tap Apps (sometimes "Application Manager").
  3. Tap locationjoystick.
  4. Tap the ⋮ menu, top-right.
  5. Tap Allow restricted settings.
  6. Return to locationjoystick and run setup again.

No ⋮ menu means your phone does not need this step.

App missing from the "Select mock location app" list

  • Open locationjoystick once. A freshly installed app never appears in the list.
  • Turn Developer Options off and back on, or restart the phone, to refresh the list.
  • On MIUI, ColorOS, and other custom Android versions, grant "Allow restricted settings" above first.
  • Still missing: reinstall the app, then restart the phone again.
  • Installed in a work profile (for example with Shelter): open Developer Options inside that same profile. Android keeps the selection per profile, so a cross-profile pick is impossible.

Mock location not detected

  • Restart the phone after you change the Developer Options setting.
  • Check works but spoofing already works: tap Skip next to the check during setup, then confirm the warning.
  • Use Skip only after you confirm spoofing works.

Overlay permission resets on restart

  • Known issue on MIUI and ColorOS.
  • Grant the permission again after each restart, or allow locationjoystick in your phone's autostart settings.

Another app holds the mock location slot

Only one app can be the mock location provider. Check which app holds it:

  1. Open the Settings app.
  2. Tap System, then Developer options. On Samsung, Developer options sits at the bottom of the main Settings list.
  3. Scroll to the Debugging group and tap Select mock location app.
  4. Read which app is selected. Anything other than locationjoystick blocks it.
  5. Tap locationjoystick in the list.
  6. Return to locationjoystick and start spoofing again.

Notes:

  • No Developer options entry: open Settings → About phone and tap Build number seven times to unlock it.
  • locationjoystick missing from the list: see "App missing from the 'Select mock location app' list" above.
  • Selecting locationjoystick clears the other app automatically. You do not need to uninstall it, but leave it closed while you spoof.

Spoofed location jumps back to your real location

Another part of your phone keeps refreshing your real position, which overrides the spoof. locationjoystick cannot change these phone-level settings. Every step below is reversible.

Do one step, then test:

  1. Open Settings → Apps → Google Play Services → Storage and tap Clear cache. Then open the ⋮ menu and tap Uninstall updates.
  2. On the same screen, open Permissions → Location and set Don't allow.
  3. Open Settings → Location and set the mode to GPS only (sometimes "Device only") instead of High accuracy.
  4. In the same menu, turn off Wi-Fi scanning and Bluetooth scanning (often under "Improve Accuracy").
  5. In your Google account settings, turn off Location History, Location Sharing, and Find My Device.
  6. Confirm no other app holds the mock location slot — see the section above.

To get your real location back:

  1. Stop spoofing in locationjoystick.
  2. Reverse the steps above that you changed. Set the location mode back to High accuracy.
  3. Restart the app you want to use, so it drops the cached spoofed position.
